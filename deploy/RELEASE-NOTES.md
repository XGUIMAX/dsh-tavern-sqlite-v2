# 0.4.5 桌面首启、清理菜单与分叉新轮修复

## 适配酒馆版本

本版适配上游 [DSH Tavern `a2008bf`](https://github.com/flizzywine/dsh-tavern/commit/a2008bf932031616fd80ec265cbdba5d0b559312)：Tavern **2.5.0**，完整提交 `a2008bf932031616fd80ec265cbdba5d0b559312`；runtime `68dff3ddaa012bdb155424f90a8d6eb779881bde` / sequence582，DSH SDK **0.1.5-rc.2**。**适配范围以本 Release 标注的酒馆版本为准，请下载前核对。**

**其他未适配的酒馆版本使用过程中可能出现运行错误。安装接入检查通过不代表运行期功能兼容；请更新到本 Release 标注的适配酒馆版本，或自行适配本插件后使用。**

酒馆升级覆盖插件区块后，请停止对应酒馆并运行一次安装维护以重接。接口变化仍需对应适配，不以安装成功推断所有运行功能兼容。

## 更新内容

- **修复桌面首次启动漏载**：安装时立即保存唯一普通插件入口，宿主和客户端无需等待作者扫描后写回配置才加载；作者后续扫描仍可用同一 ID 换成保护入口。
- **修复菜单清理报 `ctx is not defined`**：在正确的注册闭包中取得共享清理服务，经组件 props 传递。错误行、输入区提示和菜单继续委托同一清理服务；旧 0.4.4 接线可原位升级，清理失败提示改为“干净清理错误失败”。
- **修复分叉存档新轮没有后台结算且回退不可用**：上游新增的子代理过滤把正常分叉会话也跳过了。现在精确绑定的游戏分叉继续进入正文准备，登记本轮操作与身份；真正的后台、未绑定子代理仍排除，不通过清空亲本身份或放宽提交检查绕过。
- **补齐安装与恢复检查**：普通入口缺失、重复、禁用、归属不符或入口文件异常不能误判为安装成功；同包缺入口也进入修复。显式用户禁用或影响接线的覆盖会在写入前拒绝，其他配置保留；恢复仍保留安装前程序位置和配置字节。

保留 SQLite 唯一权威、物理纯尾回退、事务/CAS、旧写隔离、同连接同步、原档只读及用户手动双新 ID 分叉。

本版不会自动迁移、清理或删除存档，也不会自动补写此前已生成但未进入业务账本的轮次。自动化和隔离调用链证据不代替完整宿主、真实页面及玩法验收。
