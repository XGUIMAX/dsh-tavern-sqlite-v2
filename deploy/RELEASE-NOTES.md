# 0.4.4 回退与失败生命周期修复

## 适配酒馆版本

本版适配上游 [DSH Tavern `a2008bf`](https://github.com/flizzywine/dsh-tavern/commit/a2008bf932031616fd80ec265cbdba5d0b559312)：Tavern **2.5.0**，完整提交 `a2008bf932031616fd80ec265cbdba5d0b559312`；runtime `68dff3ddaa012bdb155424f90a8d6eb779881bde` / sequence582。**适配范围以本 Release 标注的酒馆版本为准，请下载前核对。**

**其他未适配的酒馆版本使用过程中可能出现运行错误。安装接入检查通过不代表运行期功能兼容；请更新到本 Release 标注的适配酒馆版本，或自行适配本插件后使用。**

酒馆升级覆盖插件区块后，请停止对应酒馆并运行一次安装维护以重接。接口变化仍需对应适配，不以安装成功推断所有运行功能兼容。

## 更新内容

- 修复冷会话正文回退后的投影顺序、回退完成后的恢复同步和连续重生成基准；前后台按各自可靠切点物理删尾，保留独立用户配置。
- 修复正文准备早期失败、脚本失败收尾与请求扩展失败的状态/清理衔接；清理要求可靠证据与最新尾部，活动、成功、身份不符或已有业务副作用的目标仍拒绝。
- 合入 PR #13，补齐失败状态桥的标准维护纳管；后台切点仅取同一 Session 的发轮前记录或旧业务基准，拒绝当前水位冒充前像和跨 Session 序号混用。作者迁移入口继续保留原档只读与用户手动分叉要求。
- 补齐早期启动清单的版本身份；收敛重复内核、菜单清理和业务基准，复用作者只读 Helper、最终视图与同一清理引擎，保留旧基准读取兼容。
- 修复旧 marked 菜单原位升级的重复缩进和等待/刷新尾句衔接；清理统一委托共享服务，普通回退等待保留，缺块或归属不明确的产物仍拒绝。
- 减少测试中的重复安装准备，正向接线检查共享真实标准装卸阶段；保留不同故障输入及事务、隔离、恢复安全负例，不承诺未实测的全量提速比例或玩法性能倍数。

保留 0.4.3 的标准目录一次安装、`tavern.handle` / `tavernUi.callHost` 通信、读取缓存优化、服务端 MVU，以及 SQLite 权威、同事务变量归档、revision CAS、旧写隔离和同连接同步。

原档仍只读，由用户明确分叉到新的 chatId 与原生 sessionId 后继续；本版不会自动迁移、清理或删除用户存档。发布前由主智能体执行唯一一次全量：915 项，897 通过、17 失败、1 跳过，Node 墙钟 198.5 秒。修复后，22 个失败、原跳过及实际受影响叶用例均已有有效通过证据；未跑第二次全量，不称原全量全绿。自动化与隔离装配证据不代替真实宿主、页面及玩法验收。
