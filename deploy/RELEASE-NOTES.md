## 更新内容

### 上游 537e878 适配（对账/补记/锚点）

- **正文编辑第四安装形态**：作者把编辑前"补记在途轮"升级为完整对账器 `reconcileStory`（只在 idle 时核对存档与原生会话、可证明的漏记才补写）。本插件新增第四接缝形态并**原样保留作者对账调用**；四种作者形态恰一命中才施缝，未知/多形态布局 fail-closed。
- **补记写入护栏（干净回退边界）**：对账补记不是在途发轮提交，无 `rollbackBodyOwner`；本插件在正文提交护栏内为其建立同等约束——同 session、无进行中回退、该轮无在途 body operation、回合内容齐全。**干净回退语义**：插件回退必换 branch 且存档不留回退轮痕迹，而上游对账 report 不携带生成时的 branch 身份；补记因此只能落在"当前 branch 上已有更早已提交正文轮"的存档上——回退完成后过期 report 的补记一律拒绝，**已删轮不可复活**。
- **补记走完整快照路径**：上游快路径的 header-only 快照会让补记轮的业务回退基准记成 0 楼（回退时将按 0 截空正文）；补记强制走完整快照，基准取真实楼数，附件-only 轮（空文本+附件，上游 #196 合法玩家轮）正常放行。
- **重生成锚点血缘根**：上游 `nativeAnchor` 按事件血缘根解析；临时轮末楼是投影 replace（正则/宏使投影变化即触发）时，补写锚点的 reply 必须落在 append 血缘根上，否则对账将永久误报 `anchors.lost`。物理重生成后的新正文一律用同一份采用计划算出的真实坐标覆盖临时锚点，证不明则删，不留指向别代的假锚点。

### 0.4.10 原有内容（安装单源、失败补偿与兼容/安全收口）

- **安装入口单源**：包内二入口（`install.sh`、`deploy/install.sh`）与外部发行件由 `scripts/render-install-sh.mjs` 从 `deploy/install.template.sh` ＋ `deploy/bootstrap.mjs` ＋ 当前 `package.json` 版本渲染。包内保持 URL/SHA 占位（内嵌本次 tgz 摘要会自引用），外部件在摘要产出后由同一函数填一次地址与摘要；构建门禁校验版本/数值语义与内嵌体逐字节一致。安装器版本与内容不再可能各写一份（此前的"源码树副本滞后若干代"根因）。
- **源码树入口改为本地 wrapper**：源码树 `install.sh` 与 `deploy/install.sh` 只读当前 `package.json` 与 `deploy/bootstrap.mjs`，不固定版本、URL、SHA，不内嵌获取器副本；按脚本位置定位本包，未显式 `--package` 时自动补当前包目录，离线可装卸。公开发布入口仍是构建输出 `dist/install.sh`（固定版本 URL/SHA）。
- **Linux 失败补偿**：停服未确证（窗口内原进程未退出）且原 PID 仍活时，维护不再代启第二份进程，保持原运行状态；与其它平台"不并起第二进程"一致。不新增 Linux 准入/参数/HTTP 检查。
- **卸载口径准确化**：按现场完整注释区块撤除本包注入；**半截区块、归属不明、双源装配明确拒绝**。**不承诺"坏旧包/半装残留"自动兜底**——旧 residual 兜底分支当前无生产调用者，本任务不为其接线，遇到这类现场明确拒绝。
- **公开 API 兼容与退役策略入库**：新增 [PUBLIC-API-COMPATIBILITY.md](<../PUBLIC-API-COMPATIBILITY.md>)——**56 个导出保留**（prod 44 / deploy-only 7 / test-only 1 / zero 2 / infra 2）；deprecated 只做注记不改运行时行为；移除需大版本与外部证据；不复活生产死路径；外部集成只经公开服务/命令面，**不直接写库**。**例外**：旧沙箱改兼容委托、坏缓存读取加固；保留导出与旧字段，新增回执及记账差异见兼容政策。
- **安全边界**：服务端 MVU / 卡脚本在 `node:vm` 上下文内执行，只提供超时、钩子预算与调用窗口校验等"跑飞防护"，**不是**对不可信代码的安全隔离（realm 逃逸属已知路径并按已知路径收口，不宣称完全阻断；脚本可见宿主能力改为显式 bridge，但仍与宿主同进程、同用户权限）。请只运行信任的卡与脚本。

## 收口要点

- **F001**：API 侧解析路径不使用宿主 `new Function`。
- **realm/沙箱**：realm 逃逸按已知路径收口；对脚本可见的宿主能力改为显式 bridge（不再直接暴露裸 host 对象引用）；`node:vm` 仍不是安全边界。
- **IPC**：`seq` 校验；独立 `resp` echo；`timeout` 作废唤醒（默认单槽 **8MiB**）。
- **运行时计数**：activity 改为 **atomic** 增减（跨线程不丢更新）。
- **变量**：热 cache 与 state **截断**（有界，不无界增长）。
- **legacy**：缺表视为无绑定；读写busy timeout为2秒，单条有界快照缓存按SQLite提交计数及文件/WAL身份失效；单帧输入**8MiB** / 输出**64MiB**，超预算响亮拒绝；跨project选择最高代canonical原件。
- **store**：公开 `peek` / `closeCached`。
