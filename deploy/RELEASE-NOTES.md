# 0.4.7 新上游适配与 Linux 安装维护简化

## 适配酒馆版本

本版适配上游 [DSH Tavern `7e349fa`](https://github.com/flizzywine/dsh-tavern/commit/7e349fabac54c56e9c09337efb2ee934cef254f2)：Tavern **2.5.0**，完整提交 `7e349fabac54c56e9c09337efb2ee934cef254f2`；官方 runtime `10c8f1ae1351194708c9aeefdf85b59089f01de8` / sequence586，DSH SDK **0.1.5-rc.2**。**适配范围以本 Release 标注的酒馆版本为准，请下载前核对。**

**其他未适配的酒馆版本使用过程中可能出现运行错误。安装接入检查通过不代表运行期功能兼容；请更新到本 Release 标注的适配酒馆版本，或自行适配本插件后使用。**

酒馆升级覆盖插件区块后，请停止对应酒馆并运行一次安装维护以重接。接口变化仍需对应适配，不以安装成功推断所有运行功能兼容。

## 更新内容

- **适配新增插件任务**：保留酒馆的结算前后插件任务，接入新结算接口；手动插件任务纳入回退和失败清理的静止检查，取消后等待实际任务及在途写入收尾，并拒绝迟到写入。
- **对齐最新轮次显示**：最新轮次列表按最新优先、最多12条投影；追加、回退和缓存复用时同步更新最新轮次及消息ID，保留旧作者字段布局兼容。
- **简化 Linux / WSL2 安装与卸载**：定位酒馆目录、一次命中必需接缝，直接注入区块并复制插件与加载入口；取消隔离预演、文件一致性、宿主版本与模块解析等安装检查。下载包完整性检查仍保留。
- **维护后保持原运行状态**：原来运行则按原管理方式恢复，原来停止则保持停止；不改原 systemd 单元、启动参数或环境，不检查或补 VM 启动旗标。
- 预设随机宏按轮展开继续使用上游实现，玩家插件任务开关与顺序设置保留。

保留 SQLite 唯一权威、物理纯尾回退、事务/CAS、旧写隔离、同连接同步、原档只读及用户手动双新 ID 分叉。本版不会自动迁移、清理或删除存档。自动化和源码接入验证不代替实际页面与玩法验收。
