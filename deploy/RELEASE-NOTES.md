# 0.4.6 未登记正文清理与页面刷新修复

## 适配酒馆版本

本版适配上游 [DSH Tavern `35d5b10`](https://github.com/flizzywine/dsh-tavern/commit/35d5b10c85d1a5d589a11c805e3b9d3e48393055)：Tavern **2.5.0**，完整提交 `35d5b10c85d1a5d589a11c805e3b9d3e48393055`；官方 runtime `112176cd4c79025edf59e82dcf6231efdaa58ebf` / sequence584，DSH SDK **0.1.5-rc.2**。**适配范围以本 Release 标注的酒馆版本为准，请下载前核对。**

**其他未适配的酒馆版本使用过程中可能出现运行错误。安装接入检查通过不代表运行期功能兼容；请更新到本 Release 标注的适配酒馆版本，或自行适配本插件后使用。**

最新上游相对此前适配基线的最终变化仅为文档推荐与运行清单。正文编辑后自动结算姿势的中间改动已由上游撤回，本版保留其最终行为：编辑后姿势清空，下一轮结算时再生成。

酒馆升级覆盖插件区块后，请停止对应酒馆并运行一次安装维护以重接。接口变化仍需对应适配，不以安装成功推断所有运行功能兼容。

## 更新内容

- **修复有原生回复但正文未登记时无法清理**：按最新 `turn/start` 定位本轮，识别正常文本与 `reasoning` 内容；仅当本轮业务正文未登记、未完成变量结算且运行器已静止时，提供“清除未完成回复”。身份、引用、整轮与纯尾检查继续强制；未知工具事件、活动任务及部分业务推进仍拒绝。
- **修复刷新后清理目标消失、菜单重新禁用**：首次打开、缓存复用和局部刷新都取得同一运行器证据，保留必要的编辑校验输入；旧缓存的清理许可随当前状态失效，不沿用过期目标。无法清理时返回具体原因。
- **保留上轮已保存的正文编辑**：只允许精确匹配保存内容与引用关系的旧轮编辑，清理时在同一原生 SQL 事务内保留并重排必要事件，随后重建句柄、表面与投影；无法验证的旧轮或跨边界引用继续拒绝。
- **保留正常轮的既有处理**：已登记正文的轮次，包括后台结算失败、重试耗尽或变量未变，仍使用重新结算与普通回退，不另归入未登记正文清理。

保留 SQLite 唯一权威、物理纯尾回退、事务/CAS、旧写隔离、同连接同步、原档只读及用户手动双新 ID 分叉。桌面端本次清理与回退已获用户实测确认；该确认不代表所有玩法或其他酒馆版本均已验证。

本版不会自动迁移、清理或删除存档，也不会自动补写此前已生成但未进入业务账本的轮次。
